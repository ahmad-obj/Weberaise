# WebeRaise Homepage Skeleton

This is an intentionally unfinished static skeleton for the WebeRaise agency homepage.

## Locked design decisions

- Brand: WebeRaise
- Hero headline: “Raise the standard of how your business shows up online.”
- Visual direction: dark, modern, premium-tech, typography-led
- Motion philosophy: rigid typography / unstable material / controlled depth / deliberate silence
- Hero: fluid shader reveal + perspective recession transition
- Display type direction: Instrument Sans
- UI/body direction: Geist
- Metadata direction: Geist Mono

## Locked color tokens

- Background: `#070A0F`
- Surface: `#0D111A`
- Card: `#121826`
- Text: `#F5F7FA`
- Muted text: `#A7B0C0`
- Accent blue: `#3B82F6`
- Glow blue: `#60A5FA`
- Border: `#202938`
